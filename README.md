# 🤖 Telegram Bot for 3x-ui VPN Panel

Телеграм-бот для управления VPN подписками через панель [3x-ui](https://github.com/MHSanaei/3x-ui).
Бот отслеживает сроки действия подписок и автоматически уведомляет пользователей об истечении.

---

## ✨ Возможности

- 🔔 **Автоматические уведомления** — напоминает за 7, 3, 1 день и в день истечения подписки
- 📊 **Статус подписки** — показывает срок действия, статус и лимит трафика
- 🔗 **Привязка по subId** — пользователь сам привязывает свою подписку
- 👤 **Админ-команды** — управление подписками пользователей из бота
- 🐳 **Docker** — простой деплой через docker-compose

---

## 🚀 Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/RuslanKirillov/Telegram_bot_for_3x_ui.git
cd Telegram_bot_for_3x_ui
```

### 2. Создать `.env` файл

```bash
cp .env.example .env
nano .env
```

Заполнить переменные:

```env
BOT_TOKEN=        # токен от @BotFather
PANEL_URL=        # URL панели 3x-ui, например https://1.2.3.4:54321
PANEL_USER=       # логин от панели
PANEL_PASS=       # пароль от панели
ADMIN_ID=         # твой Telegram ID (узнать у @userinfobot)
```

### 3. Запустить

```bash
docker-compose up -d
```

База данных сохраняется в папке `./data` — не удаляется при перезапуске.

## 🛠 Команды бота

### Пользователь
| Команда | Описание |
|--------|----------|
| `/start` | Главное меню |
| `/link <subId> [название]` | Привязать подписку |
| `/unlink <subId>` | Отвязать подписку |
| `/status` | Статус подписок |

### Администратор
| Команда | Описание |
|--------|----------|
| `/admin_link <chat_id> <subId> [название]` | Привязать подписку пользователю |
| `/admin_unlink <chat_id> <subId>` | Отвязать подписку у пользователя |
| `/admin_users` | Список всех пользователей |
| `/check` | Запустить проверку вручную |
